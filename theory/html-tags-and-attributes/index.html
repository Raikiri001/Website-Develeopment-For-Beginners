HTML Tags and Attributes

HTML is built from elements. Each one names a piece of content, sits inside a tree of other elements, takes up space in one of two ways, and can carry attributes the tag name alone cannot express. This is what those pieces are and how they fit together.

Side by side

Every part, compared

Every row asks the same question of all of them, so you can read straight across to see what actually differs.

An element names a piece of content, nesting arranges elements into a tree, the document gives that tree its fixed outer shape, attributes add what the name cannot carry, block and inline decide how space is taken, and the name you choose decides what the page means to anything not looking at it.
