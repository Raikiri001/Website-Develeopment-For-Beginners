File Paths

Every href, src and url() holds a path: directions from one file to another. The browser follows them literally, from a starting point you have to know, which is why a wrong path is so often invisible until something fails to load.

Every part, compared

Every row asks the same question of all of them, so you can read straight across to see what actually differs.

A path is directions. A relative one starts from the folder of the file it is written in, an absolute one starts from a fixed point, and resolving either is a matter of taking one step at a time from the right place.
