HTML Overview

HTML is how you hand a browser some content and say what each part of it is. This is what that means, the order a page is read in, why the tag you pick matters more than how it looks, and how a page reaches the other files it needs.

Side by side

Every part, compared

Every row asks the same question of all of them, so you can read straight across to see what actually differs.

HTML marks up content with its meaning rather than its appearance, an element is a tag wrapped around some content, a page is read from top to bottom in the order you wrote it, the tag you choose is what carries the meaning, and a page reaches everything else it needs through paths. Everything else in HTML is built on top of those ideas.
