How Browsers Parse HTML & CSS

A browser reads files from top to bottom. Raw bytes are converted to characters, then tokenised. HTML tokens build the DOM tree, while CSS rules build the CSSOM tree. The browser then combines both trees into a render tree, which it lays out and paints to produce the visual page.
