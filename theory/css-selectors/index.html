CSS Selectors

A CSS rule needs a selector to say which elements it applies to. There are three kinds, and they differ in what they match on: what an element is called, where it sits, or what condition it is in.

When two match

Which selector wins?

Two rules can both match the same element and set the same property. Specificity decides between them, counted in this order.

    Three ways to describe an element: by its name, by where it sits, or by what is true of it. When two rules both match, the more specific selector wins, and a tie goes to whichever was written last.
