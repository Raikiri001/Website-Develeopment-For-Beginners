CSS Selectors

A CSS rule needs a selector to say who it applies to. A selector is a pattern, and the browser tests every element against it. This is how that pattern is built, what it can match on, and what happens when two of them match the same element.

How a conflict is settled

Counting specificity

When two rules match the same element and set the same property, the browser counts what each selector is made of, in this order. It only looks at the next group if the one above ties.

    A selector is a pattern, built from simple parts, joined in ways that change its meaning, able to match a state the HTML never wrote down, and weighed against any other selector matching the same element. Learn the shape and any selector you meet later reads the same way.
