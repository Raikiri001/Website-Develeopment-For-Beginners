Theory

CSS Properties

A CSS rule is a list of properties, and each one changes exactly one thing. They fall into four groups, and knowing which group a property belongs to tells you what it will change and, just as usefully, what it will not.

Side by side

The four groups, compared

Every row asks the same question of all of them, so you can read straight across to see what actually differs.

Four groups, four jobs: text and colour change how the words look, the box model changes how big the box is, backgrounds and borders paint that box, and layout decides where the boxes sit.
