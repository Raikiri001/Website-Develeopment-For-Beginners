CSS Properties

A CSS rule is a list of properties, and each one is a single named setting on an element. This is what a property is, what you are allowed to put after the colon, what a property does when you never set it, and how to define one of your own.

Every part, compared

Every row asks the same question of all of them, so you can read straight across to see what actually differs.

A property is one setting, a value is what you set it to, a shorthand sets several at once, anything you never set still has a value, and a custom property lets you name a value and reuse it. Those ideas hold for every property in CSS, including the ones you have not met yet.
