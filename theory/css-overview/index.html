CSS Overview

CSS is the language that decides how a page looks, while the HTML underneath it decides what the page is. This is what a CSS rule is made of, how a stylesheet reaches a page, why one rule can style a hundred elements, and what happens when several rules land on the same one.

Side by side

Every part, compared

Every row asks the same question of all of them, so you can read straight across to see what actually differs.

CSS sets appearance and leaves meaning to the HTML, a rule is a selector followed by a block of declarations, a stylesheet only applies where a page links to it, one rule reaches every element its selector matches, and an element is styled by every rule that matches it. Everything else in CSS is built on top of those ideas.
