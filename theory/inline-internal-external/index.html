Inline, Internal, External

CSS can be attached to a page in exactly three places. All three produce real CSS and use the same properties. What differs is how far each one reaches and which one wins when they disagree.

Side by side

The three, compared

Every row asks the same question of all three, so you can read straight across to see what actually differs.

When they disagree

Which one wins?

Put a colour on the same heading in all three places and only one of them can take effect. The browser settles it in this order, from the top down.

      That is the whole picture: one file for a site, one block for a page, one attribute for one element, and a cascade that settles any argument between them.
