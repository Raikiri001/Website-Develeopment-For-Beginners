Modern CSS Layouts

Layout is deciding where things sit on the page. CSS has two tools built for that job, Flexbox and Grid, and a default arrangement underneath both of them. This is what normal flow already gives you, the one question that decides between the two tools, what each of them does, and why a real page uses both at once.

Side by side

Every part, compared

Every row asks the same question of all of them, so you can read straight across to see what actually differs.

Normal flow lays a page out before you write anything, Flexbox arranges content along one axis, Grid arranges it into rows and columns at once, and a real page nests the second inside the first. The question that picks between them is always the same: how many directions does this arrangement have?
