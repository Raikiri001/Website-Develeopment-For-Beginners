The Box Model

Every element a browser draws is a box, and that box is built from four areas you cannot see all of: the content, the padding around it, the border around that, and the margin outside. This is the invisible anatomy of an element, and what the width you set actually measures.

Side by side

Every part, compared

Every row asks the same question of all of them, so you can read straight across to see what actually differs.

Every element is a box of four nested areas, padding is the space inside it, the border is the edge you can see, margin is the space it keeps clear outside itself, and the width you set only covers the whole box when you ask it to. Get those five straight and an element is never a size you cannot account for.
