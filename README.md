# Web Dev For Beginners

An interactive website for learning web development, combining short **theory**
explainers with hands-on **practical** activities. 

**Live site:** https://raikiri001.github.io/Web-Dev-For-Beginners/

## What's here

- **Theory: How Browsers Parse HTML and CSS.** Step through a browser's
  parser one token at a time and watch it build the DOM tree, the CSSOM
  tree and the render tree in real time.
- **Practical: HTML Structure Trainer.** Thirty drag-and-drop problems
  that train you to arrange HTML elements in the correct order, from your
  first heading to a full semantic page layout.
- **Dashboard.** Tracks what you've completed, what's in progress and
  what you haven't tried yet, right in your browser.

More activities will be added over time; the homepage lists them
automatically as they're added (see `data/activities.json`).
